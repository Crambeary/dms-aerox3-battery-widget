# Screenshot provenance

`../screenshot.png` is an existing committed desktop capture showing the
Aerox 3 Battery popout, discharging at 100%. `popout.png` is an existing
smaller bar-only crop despite its filename. Neither was generated or
retouched for the README refresh on 2026-11-07. The original capture date
and DMS version were not recorded, so these are illustrative captures of
this personal setup rather than evidence of current version compatibility.

To refresh: open the actual widget on a DMS desktop with the mouse connected,
then capture just its bar pill and popout. Exclude other apps and private
notification content. Do not substitute simulated battery values.
